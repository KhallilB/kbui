# Tokens

Every value comes from `packages/tokens/tokens.json`. This page reads the generated token names, so it never drifts from the source. Swatches follow your system's light or dark setting.

Components use semantic colors and scale tokens. Palette colors are building blocks for other tokens only.

## Semantic colors

<ColorPalette>
  {Object.entries(tokens.color).map(([name, variable]) => (
    <ColorItem key={name} title={`color.${name}`} subtitle={variable} colors={{ [name]: `var(${variable})` }} />
  ))}
</ColorPalette>

## Palette

<ColorPalette>
  <ColorItem title="white, black" subtitle="--kb-white, --kb-black" colors={{ white: `var(${tokens.white})`, black: `var(${tokens.black})` }} />
  {["gray", "blue", "red"].map((family) => (
    <ColorItem
      key={family}
      title={family}
      subtitle={`--kb-${family}-*`}
      colors={Object.fromEntries(Object.entries(tokens[family]).map(([step, variable]) => [step, `var(${variable})`]))}
    />
  ))}
</ColorPalette>

## Component tokens

<table>
  <tbody>
    {["button", "input", "dialog"].flatMap((component) =>
      Object.entries(tokens[component]).flatMap(([key, value]) =>
        typeof value === "string"
          ? [<tr key={value}><td><code>{value}</code></td></tr>]
          : Object.values(value).map((variable) => <tr key={variable}><td><code>{variable}</code></td></tr>),
      ),
    )}
  </tbody>
</table>
