# Tokens

The design tokens live in `packages/tokens/tokens.json`. This page reads from that file and displays swatches in the current theme.

Use semantic colors such as foreground or accent when styling your app. Spacing, radius, and type scales keep related values consistent. Component tokens let you change a particular control without changing the whole theme. Raw palette colors are the building blocks for those tokens.

## Semantic colors

<ColorPalette>
  {Object.entries(tokens.color).map(([name, variable]) => (
    <ColorItem key={name} title={`color.${name}`} subtitle={variable} colors={{ [name]: `var(${variable})` }} />
  ))}
</ColorPalette>

## Visualization roles

Each role has a mark, a tint and text for the tint. See `docs/tokens.md` for when to use each.

<ColorPalette>
  {["current", "visited", "changed", "error", "discarded", "frontier", "path"].map((role) => (
    <ColorItem
      key={role}
      title={`viz.${role}`}
      subtitle={`--kb-viz-${role}, -bg, -fg`}
      colors={{
        mark: `var(${tokens.viz[role]})`,
        tint: `var(${tokens.viz[`${role}-bg`]})`,
        text: `var(${tokens.viz[`${role}-fg`]})`,
      }}
    />
  ))}
</ColorPalette>
