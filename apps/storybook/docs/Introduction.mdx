# kbui

kbui is the design system shared across our projects. Design tokens define every value, plain CSS defines every style, and a thin React layer built on Base UI provides behavior.

## Using kbui in a project

Build kbui, then add it by path from your project:

```bash
cd ~/proj/kbui && bun run build
cd ~/proj/<your-app> && bun add ../kbui/packages/react ../kbui/packages/css
```

```tsx
import "@kbui/css/styles.css";
import { Button, Dialog, Panel, Input, Status } from "@kbui/react";
```

Set `data-theme="light"` or `"dark"` on `<html>` to choose a theme. Without it, kbui follows the system setting.

## Navigating this Storybook

**Foundations / Tokens** lists every color, spacing, radius and type token, read from `tokens.json`.

Under **Components**, each component has a Docs page with its props and live examples. Use the theme switch in the toolbar to view a story in light or dark. **Showcase** composes those components into full screens, with and without a product skin.

Every story is also an accessibility test. A violation fails CI.

## Structure

The tokens package holds every value. The CSS package turns those values into styles keyed on `kb-` classes and `data-*` attributes. The React package adds behavior from Base UI and maps props onto those classes and attributes.

Each component stylesheet starts with an `Anatomy:` line that lists the classes and attributes it expects. That line is the contract between the CSS and any renderer.

## Direction
