# kbui

kbui is the design system we share across our projects. The look is plain CSS built from design tokens, and a small React layer on Base UI handles behavior.

## Using it in a project

Build kbui, then add it by path from your project:

```bash
cd ~/proj/kbui && bun run build
cd ~/proj/<your-app> && bun add ../kbui/packages/react ../kbui/packages/css
```

```tsx
import "@kbui/css/styles.css";
import { Button, Dialog, Input } from "@kbui/react";
```

Set `data-theme="light"` or `"dark"` on `<html>` to pick a theme. If you leave it off, kbui follows the system setting.

## Finding your way around

**Foundations / Tokens** lists every color, spacing, radius and type token, read from `tokens.json`.

Under **Components**, each component has a Docs page with its props and live examples. Use the theme switch in the toolbar to see a story in light or dark.

Every story is also an accessibility test. If the scan finds a problem, CI fails.

## How it's put together

The tokens package holds every value. The CSS package turns them into styles, keyed on `kb-` classes and `data-*` attributes. The React package adds behavior from Base UI and maps props onto those classes and attributes.

Each component's stylesheet starts with an `Anatomy:` line listing the classes and attributes it expects. That line is the agreement between the CSS and whatever renders it.

The repository has more: `README.md`, `docs/architecture.md`, `docs/tokens.md`, the guides in `docs/guides/` and the decision records in `docs/decisions/`.
