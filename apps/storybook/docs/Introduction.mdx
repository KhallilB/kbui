## Add kbui to your app

The React package includes component styles and CSS tokens. Bring React and React DOM 19 or later. This command uses Bash; [Get started](../setup/) has ready-to-copy commands for npm, pnpm, Yarn, and Bun.

{/* x-release-please-start-version */}
```bash
bun add @kb.ui/react@0.10.2
```
{/* x-release-please-end */}

```tsx
import "@kb.ui/react/styles.css";
import { Button } from "@kb.ui/react";

export function App() {
  return <Button>Save changes</Button>;
}
```

Import the stylesheet once, where your app starts. Components follow your system theme by default. Set `data-theme="light"` or `"dark"` on `<html>` to choose one explicitly.

## Using this reference

Choose a component in the sidebar for its props and examples. Use the toolbar to switch between **System**, **Light**, and **Dark**. Useful states, like errors and empty values, sit alongside the main example. You can edit props in the controls and open the code under each preview.

**Foundations / Tokens** covers colors, spacing, typography, and theme overrides. **Layout / Grid** shows responsive arrangements.

## Make it yours

Start with [themes and styling](../setup/themes/) to adjust tokens without rebuilding the components. The [usage guide](https://github.com/KhallilB/kbui/blob/main/docs/guides/using-kbui.md) covers upgrades, typed tokens, and troubleshooting.

Examples run interaction and accessibility checks in CI. Check your own compositions with a keyboard and assistive technology too.
