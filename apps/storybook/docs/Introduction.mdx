# kbui

kbui is a React component library with shared design tokens and plain CSS. Use its default light and dark themes, or adjust the tokens to fit your app. Components use Base UI for interaction.

## Using kbui in a project

Install the release into your React app. The React package includes component styles and CSS tokens; React and React DOM 19 or later are peer dependencies. These commands use Bash (Git Bash or WSL on Windows).

{/* x-release-please-start-version */}
```bash
KBUI_VERSION=0.7.0
bun add "https://github.com/KhallilB/kbui/releases/download/v${KBUI_VERSION}/kbui-react-${KBUI_VERSION}.tgz"
```
{/* x-release-please-end */}

```tsx
import "@kbui/react/styles.css";
import { Button } from "@kbui/react";

export function App() {
  return <Button>Save changes</Button>;
}
```

Set `data-theme="light"` or `"dark"` on `<html>` to choose a theme. Without it, kbui follows the system setting.

The [usage guide](https://github.com/KhallilB/kbui/blob/main/docs/guides/using-kbui.md) covers upgrades, optional typed tokens, local path installs and troubleshooting. The [Examples page](../examples/) shows components working together.

## Navigating this Storybook

**Foundations / Tokens** shows the shared colors, spacing, corner radii, and typography from `tokens.json`.

Under **Components**, each component has a Docs page with its props and live examples. Use the theme switch in the toolbar to view a story in light or dark. Use **Layout** for responsive Grid examples.

Stories run automated interaction and accessibility checks in CI. These checks catch common problems; you should also test components in your app with the keyboard and assistive technology.

## Structure

The tokens package holds every value. The CSS package turns those values into styles keyed on `kb-` classes and `data-*` attributes. The React package adds behavior from Base UI and maps props onto those classes and attributes.

Each component stylesheet starts with an `Anatomy:` line that lists the classes and attributes it expects. That line is the contract between the CSS and any renderer.
