## Verification and publication

The site is deployed at https://kbui.kcb.pro/. Historical checks below retain the artifact and environment they tested. Earlier regression baseline, verified on 2026-10-25:

- `bun run check` passed: package builds, repository lint, TypeScript, unit tests and package-content checks.
- `bun run --filter @kbui/storybook test:site` passed 154 browser cases across 320, 390, 768, 1024, 1280 and 1440-pixel widths and forced colors.
- `bun run test:stories` passed 210 normal/reduced-motion browser cases with accessibility scans, including inline copy feedback and dropdown pointer/keyboard focus recovery.
- `bun run --filter @kbui/storybook verify:release` passed 18 browser journeys in short-screen Chromium and mobile WebKit portrait/landscape: shared-state refresh and history, delayed readiness, stalled-preview retry, motion/reduced motion with viewport-centered dialogs, retained pending/expanded canvases, rapid state switching, stable Button sizing, dropdowns, wrapped code and default live previews for every component. - `RELEASE_CHECK=surfaces bun run --filter @kbui/storybook verify:release` passed all three targeted browser profiles for shared page entrances in normal/reduced motion, stationary panel containers, page overflow, dropdowns, wrapped code and live component defaults.
- `bun run --filter @kbui/storybook build:site` produced the combined static output. Its catalog verification checks 88 story/documentation targets.
- Source coverage passed 13 cases, including API parsing, generated module syntax, inherited props, helper dependencies, themes, ordered syntax ranges, TSX calls, CRLF, UTF-16 offsets and import-only usage boundaries.

- `bun run --filter @kbui/storybook verify:code` passed for 173 complete React modules and 173 concise snippets (73 catalog states, 96 playground combinations, four curated states).
- `bun run --filter @kbui/storybook verify:previews` passed all 146 live preview cases (73 examples at 320px and 1280px) and shared site code panels against the combined static preview, including expanded/compact sizing for every state, short-screen state switches with open code, fluid surface widths, filled Panel rows, overlay bounds, panel collapse, code-open geometry, real clipboard round trips, import-and-usage copy with inline confirmation and stable panel height, native dropdown selection and compact focus checks, native long-code keyboard scrolling and shared panels on the playground/curated routes.

## Maintenance skill

Use `kbui-docs-features` when changing kbui capabilities or auditing this register. It routes updates to the canonical owners above, checks links and shared examples, and records only observed implementation and publication states. The installed skill is shared between the local Claude and Codex skill directories; its machine-local installation is not part of the site bundle.
